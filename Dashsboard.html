SQL Injection en /users

Descripción

La entrada del usuario no está siendo sanitizada, permitiendo inyección de comandos en la BD.

Evidencia

Fix Coach (IA)

Usa consultas parametrizadas o un ORM para evitar que el input modifique la estructura del query.

Solución (Python + SQLAlchemy)

from sqlalchemy import text

query = text("SELECT * FROM users WHERE id = :id")
result = db.session.execute(query, {"id": user_id})
